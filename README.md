**文件打开方式路由器**

1. 本程序不是解压软件、阅读器或编辑器，而是“打开方式路由器”，它只负责判断文件所在目录，并调用你配置的外部程序。
2. 请先选择一个真实存在的兜底程序。当前文件未命中任何规则时，本程序会使用该兜底程序打开文件；按住【Shift键】打开文件时，也会强制使用兜底程序。
3. 请将本程序设置为对应文件类型的默认打开程序。设置完成后，双击打开这些文件时，本程序会自动根据文件所在目录，将其转交给指定的程序打开。目录越具体则优先级越高。
4. 可以复制多份本程序并重新命名，例如 FileOpenRouter_压缩包.exe、FileOpenRouter_pdf.exe，不同名称的程序会使用不同配置文件，适合分别管理 压缩包、PDF 等不同文件类型。
5. 注意：兜底程序不要选择本程序自身，否则可能造成循环调用。
